A modern and responsive Family Information Management System built using HTML, CSS, JavaScript, PHP, and MySQL. This project helps users securely manage personal and family records in one place. It provides an easy-to-use dashboard for storing, updating, searching, and managing family information.

✨ Features
🔐 Secure Admin Login & Logout
👤 Personal Information Management
👨 Father & Mother Details
👨‍👩‍👧 Family Member Management
🎓 Education Details
💼 Occupation Information
🏠 Permanent & Current Address
🏦 Bank Details
🆔 Aadhaar, PAN & Other ID Details
💊 Medical Information
📞 Emergency Contact Details
📷 Photo Upload
📄 Document Upload
🔍 Search Records
✏️ Edit Records
🗑 Delete Records
📊 Dashboard Statistics
📱 Fully Responsive Design
🌙 Dark Mode Support
🖨 Print-Friendly Pages
🛠️ Technologies Used
HTML5
CSS3
JavaScript (ES6)
